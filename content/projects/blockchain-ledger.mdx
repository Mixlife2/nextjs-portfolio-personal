Personal project exploring blockchain development and smart contract integration. Built a backend server with Node.js/Express that integrates with a local Hardhat blockchain node and implements ERC20 token functionality.

## Features

- Local blockchain setup with Hardhat for development and testing
- ERC20 token smart contract implementation
- RESTful API endpoints for token operations
- Express.js backend architecture
- Integration testing with blockchain transactions

## Tech Stack

Node.js, Express.js, Hardhat, Solidity, Ethereum, ERC20

This project helped me understand blockchain fundamentals, smart contract development, and the challenges of building decentralized applications.
