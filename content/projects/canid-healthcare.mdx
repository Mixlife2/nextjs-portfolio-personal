As a Software Engineer at [Canid](https://www.canid.com), I contribute to a comprehensive healthcare SaaS platform serving medical practices across the country. My work spans the full stack, from user-facing product features to backend infrastructure and database architecture.

## Key Contributions

### Frontend Development
- Led UI component migrations to shadcn/ui design system, improving consistency and maintainability across the platform
- Built complex React/TypeScript interfaces for clinical workflows, including immunization tracking and IIS (Immunization Information System) registry integrations
- Implemented patient eligibility verification flows and borrowing systems for multi-practice environments
- Developed responsive, accessible components with attention to healthcare-specific UX requirements

### Backend & Infrastructure
- Designed and implemented RESTful APIs with Node.js for critical healthcare operations
- Wrote complex SQL queries and migrations for PostgreSQL databases, including permissions systems and audit logging
- Built AWS Lambda functions for analytics tracking and background job processing
- Implemented guardian tracking systems and activity logs for compliance and accountability

### Product Features
- Shipped end-to-end features for immunization management, including vaccine inventory and patient record synchronization
- Built notification systems with timezone handling for distributed teams
- Implemented search functionality with proper debouncing and optimization
- Contributed to multi-practice user experience improvements, enabling seamless practice switching

## Technology Stack

- **Frontend:** React, TypeScript, shadcn/ui, Tailwind CSS
- **Backend:** Node.js, Express, PostgreSQL
- **Cloud:** AWS Lambda, serverless architecture
- **Tools:** Git, CI/CD pipelines, code review processes

## Impact

Through ~87 merged pull requests across multiple repositories, I've helped build reliable, scalable features that healthcare providers depend on daily. Every feature is built with security, compliance, and user needs at the forefront.
